# Технології розробки та тестування програмних продуктів

## Java Engineering: Професійна розробка та дизайн ПЗ

> **Декларація курсу.** Академічна доброчесність, Закон № 4742-IX, використання ШІ та цитування - у [DISCLAIMER.md](DISCLAIMER.md).

Курс є частиною дисципліни «Технології розробки та тестування програмних продуктів» для студентів 2-го курсу Одеського національного університету імені І. І. Мечникова (ОНУ). Розрахований на слухачів із базовими навичками програмування на C++.

---

## Про курс та структуру

**Фокус курсу:** перехід від синтаксису до інженерного проєктування надійних систем (SOLID, Design Patterns, Clean Code, багатопотоковість, діагностика) із використанням професійних інструментів (Git, Maven, тестування, логування).
