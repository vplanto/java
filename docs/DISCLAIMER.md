# Декларація про академічну доброчесність

**Курс:** Java Engineering — Професійна розробка та дизайн ПЗ  
**Заклад:** Одеський національний університет імені І. І. Мечнікова (ОНУ)

---

## 1. Правова основа

Матеріали та вимоги цього курсу узгоджені з принципами **академічної доброчесності**, визначеними [Законом України № 4742-IX](https://zakon.rada.gov.ua/laws/show/4742-IX) «Про внесення змін до Закону України "Про освіту" щодо академічної доброчесності».

**Академічна доброчесність** — це сукупність етичних правил і норм, якими керуються учасники освітнього процесу під час навчання, викладання та проведення наукових досліджень.

---

## 2. Що вважається порушенням

До порушень академічної доброчесності належать, зокрема:

- **Плагіат** — представлення чужих ідей, коду, текстів або рішень як власних без належного посилання на джерело.
- **Самоплагіат** — повторне використання власних раніше зданих робіт без дозволу викладача.
- **Фабрикація** — вигадування даних, результатів тестів або фактів у звітах і захистах.
- **Шпаргалки та несанкціонована допомога** на контрольних заходах (іспит, залік, усний захист).
- **Договірне списання** — замовлення або виконання робіт іншими особами від імені студента.
- **Недеклароване використання ШІ** — здача згенерованого коду або тексту без розкриття факту використання та без особистої перевірки й відповідальності за результат.

---

## 3. Використання штучного інтелекту (ШІ)

Курс виходить з позиції **Agentic Pipeline**, а не «Vibe Coding»:

| Дозволено | Заборонено |
|-----------|------------|
| Використовувати ШІ як інструмент після власного проєктування (вимоги, API, архітектура) | Здавати код, призначення якого ви не можете пояснити («Magic Code») |
| Генерувати чернетки за чіткими інженерними промптами | Виправдовувати помилки фразою «ШІ так згенерував» на захисті або code review |
| Рефакторити, тестувати та перевіряти згенерований код самостійно | Сліпо копіювати відповіді ШІ на іспит або в practica без розуміння |
| Декларувати використання ШІ у README або звіті, якщо це вимагає викладач | Представляти згенеровану роботу як повністю самостійну без перевірки |

**AI Ownership:** розробник несе повну відповідальність за кожен рядок коду, який здає. Детальні критерії фінального проєкту — у [Agentic Pipeline vs Vibe Coding](02_semester/workshop/engineering/vibe_coding.md).

## 4. Цитування та джерела

- Офіційний реєстр першоджерел курсу: **[sources.md](sources.md)** — використовуйте позначення `[N]` при посиланнях на стандарти, специфікації та публікації.
- Визначення термінів — у **[глосарії](02_semester/glossary.md)**; не дублюйте в роботах повні визначення без потреби.
- Матеріали лекцій і practica призначені для **особистого навчання**. Публікація або передача повних фрагментів третім особам без дозволу викладача не допускається.
